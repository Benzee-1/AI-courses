Introduction

Cette documentation décrit l'installation et la configuration de la plateforme Apache Airflow.

ℹ️ Cette procédure est destinée aux administrateurs Linux et équipes DevOps.

Architecture cible

L'architecture repose sur plusieurs composants.

Serveur Rôle Ports
AIRFLOW-01 Webserver + Scheduler 8080
PGSQL-01 PostgreSQL 5432
REDIS-01 Message Broker 6379

Pré-requis

  • ✅ Linux Oracle 9
  • ✅ Python 3.12
  • ✅ PostgreSQL
  • ✅ Redis
  • ✅ Accès sudo
⚠️ Vérifier que SELinux et le firewall autorisent les flux réseau nécessaires.

Installation

Création de l'environnement virtuel


python3.12 -m venv airflow
source airflow/bin/activate

Installation Airflow


pip install apache-airflow
Afficher les paramètres avancés

Ajouter ici toute la configuration complémentaire.

Validation

✅ L'installation est conforme si l'interface Airflow est accessible. 

airflow version

Troubleshooting

Erreur Cause Résolution
Connection refused Port fermé Vérifier firewall
DB timeout PostgreSQL indisponible Tester le réseau
